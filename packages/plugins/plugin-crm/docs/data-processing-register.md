# Data-processing register

Version: 2026-10-04b

Which systems hold or process personal data for Partners in Biz and its clients, what they get, where they are, how long they keep it, and whether an agreement (a data-processing agreement, "operator agreement" under POPIA section 21) is on file. The CRM seeds this table from this file (read-only: nothing in the plugin edits a row; to change one, edit this file and ship it).

How to read the columns:

- **region**: where the data sits. POPIA section 72 limits sending personal data out of South Africa unless the receiver is bound by comparable rules, the person agrees, or a contract needs it.
- **agreement**: `on file` only when the agreement was seen and kept. `unverified` means nobody has checked: it is a to-do, not a yes.
- **sensitive clients**: the first word is the rule the Cockpit and Jev routing read. `cleared` means a client flagged sensitive may have its data handled there. `not cleared` means it must not. `conditional` means only with the stated condition. Until an agreement is on file the answer for an outside processor is `not cleared`.
- Nothing here is legal advice; the owner confirms each `unverified` line.
