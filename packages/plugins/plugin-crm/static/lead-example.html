Lead form on a page

This is a copy of what a client's page looks like with the form on it. The key below is a placeholder, so sending this form shows the error a wrong key gives. Your real snippet comes from create-lead-endpoint or list-lead-sources.

The form

The snippet

<script async src="https://YOUR-PAPERCLIP-HOST/_plugins/UUID/ui/lead.js"
        data-pib-lead="pibl_YOUR_KEY"></script>

Optional attributes: data-consent (the wording by the tick box), data-privacy (a link), data-success (the thank-you), data-accent (#RRGGBB), data-fields (name,email,phone,company,message), data-target (a CSS selector).

From the client's own server

curl -sS -X POST 'https://YOUR-PAPERCLIP-HOST/api/plugins/partnersinbiz.crm/webhooks/lead' \
  -H 'content-type: application/json' \
  -d '{"key":"pibl_YOUR_KEY","name":"Jane Smith","email":"jane@example.com","message":"Hello"}'

A browser on another site cannot post to that address directly (the host sends no CORS headers), which is why the page form lives in an iframe. A server can. A server that should skip the browser checks signs each request with a signing secret. A person makes that secret on the client's Lead forms card in the CRM (it is shown once); an agent never sees it.
